# Linux Fundamentals — Learning Notes

## Introduction

This document contains notes and practical exercises from my first Linux learning sessions.

I used Ubuntu through Windows Subsystem for Linux (WSL) to practice basic terminal commands and file management.

## 1. Terminal Navigation

| Command | Description |
|---|---|
| `pwd` | Display the current working directory |
| `ls` | List files and directories |
| `cd directory` | Move into a directory |
| `cd ..` | Move to the parent directory |
| `cd ~` | Return to the home directory |

## 2. File and Directory Management

| Command | Description |
|---|---|
| `mkdir folder` | Create a directory |
| `touch file.txt` | Create an empty file |
| `cp file.txt copy.txt` | Copy a file |
| `mv file.txt newname.txt` | Rename or move a file |
| `rm file.txt` | Delete a file |
| `rmdir folder` | Remove an empty directory |

## 3. Absolute and Relative Paths

An absolute path starts from the root directory (`/`).

Example:

`/home/username/Documents`

A relative path starts from the current working directory.

Example:

`Documents/`

Understanding the difference helps me navigate the Linux file system more efficiently.
