## Practical Git Commands

During my first learning sessions, I practiced the following commands using Git Bash.

| Command | Purpose |
|---|---|
| `git status` | Check the current repository status |
| `git add .` | Stage changes in the current directory |
| `git commit -m "message"` | Save a snapshot of staged changes |
| `git push` | Upload local commits to the remote repository |
| `git pull` | Download and integrate remote changes |
| `git branch` | List local branches |
| `git switch -c feature-branch` | Create and switch to a new branch |
| `git merge feature-branch` | Merge changes from another branch |
